# SOLE OFFICIAL THEME

Theme: Agentic AI

Moving beyond conversational chatbots. HackSprint '26 challenges 4-member builder squads to architect autonomous software agents capable of proactive perception, multi-stage planning, sandboxed tool usage, and self-correcting execution.

NATIONAL 24-HOUR AUTONOMOUS CODE SPRINT

The Autonomous Era: Architecting Intelligence That Reasons, Plans, and Acts

The paradigm of AI has shifted from text-generation prompts to autonomous multi-agent agency. In this nationwide 24-hour hackathon, participants will construct cognitive architectures that autonomously decompose problems, select and call external tools safely via protocols such as Model Context Protocol (MCP), inspect real-world feedback, and self-heal runtime failures.

PILLAR 01

Multimodal Grounding

Perceive unstructured environments, terminal streams, GUI windows, and code ASTs with grounded spatial and semantic context.

PILLAR 02

Cognitive Planning

Formulate dynamic ReAct reasoning chains, hierarchical goal trees, and peer-to-peer delegation graphs without hardcoded scripts.

PILLAR 03

Sandboxed Tool Use

Safely invoke local and cloud microservices, Docker testbeds, system terminals, and vector databases via standardized tool interfaces.

PILLAR 04

Reflection & Self-Healing

Inspect tool failure traces, reflect on sub-goal drift, synthesize regression tests, and autonomously correct errors before final output.
